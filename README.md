# Günlük Notlarım - Android SQLite Uygulaması

Bu proje, Sistem Tasarımı ve Yazılım Mühendisliği (SSTE) dersi için geliştirilmiş, yerel veritabanı (SQLite) kullanan bir Android mobil uygulamasıdır. 

Projede arayüz tamamen özelleştirilmiş olup, "Koyu Lila" (Dark Lilac) renk teması kullanılmıştır. Uygulama, Android cihazlarda internetsiz ve hızlı bir şekilde not alma imkanı sunar.

## 🚀 Proje Özellikleri (CRUD İşlemleri)

* **Not Ekleme (Create):** Kullanıcıların metin kutusuna yazdıkları notları SQLite veritabanına kaydeder.
* **Notları Listeleme (Read):** Veritabanındaki tüm notları, özel tasarlanmış lila renkli bir liste (ListView) üzerinde anlık olarak gösterir.
* **Not Güncelleme (Update):** Listeden seçilen bir notun metnini düzenleyip veritabanında güncellemeyi sağlar.
* **Not Silme (Delete):** Listeden seçilen notu veritabanından kalıcı olarak siler.
* **Özel Tasarım:** Klasik Android renkleri yerine, tamamen XML üzerinden kişiselleştirilmiş modern bir arayüz.

## 🛠️ Kullanılan Teknolojiler

* **Platform:** Android
* **Dil:** Java
* **Veritabanı:** SQLite (`SQLiteOpenHelper`)
* **Arayüz (UI):** XML (LinearLayout, özel ListView tasarımı)
* **Geliştirme Ortamı:** Android Studio
